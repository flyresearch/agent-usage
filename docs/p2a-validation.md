# P2a validation index

Current validation commands, covered contracts, and limitations are maintained in [minimal-validation.md](minimal-validation.md).

The public repository contains synthetic fixtures and reproducible checks. Private operational inventories, raw logs, model mappings, usage measurements, and development-machine performance traces are not part of the public evidence set.

Protocol behavior is documented in [protocol-v1.md](protocol-v1.md); pinned source analysis is in [dependency-review.md](dependency-review.md), [codex-response-usage.md](codex-response-usage.md), and [codex-fork-usage.md](codex-fork-usage.md). The collector's successful read flag must not be interpreted as complete historical coverage.
